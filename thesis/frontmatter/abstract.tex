\chapter*{Abstract}

This dissertation explores whether small recurrent neural networks can model the sound of a Boss DS-1 distortion pedal well enough to be used in a real-time audio plugin. It compares two recurrent architectures, Long Short-Term Memory (LSTM) and Gated Recurrent Unit (GRU), using the same dataset, training process, and plugin deployment method.

A matched dry/wet dataset was recorded for the project. The dry guitar signal was used as the model input, and the signal recorded through a physical Boss DS-1 pedal was used as the target output. The pedal was recorded at one fixed setting, so the results apply to that captured condition rather than to every DS-1 setting or unit.

The models were trained in Python using a PyTorch workflow based on CoreAudioML. Both models use a mono recurrent design with one recurrent layer, hidden size 24, a dense output layer, and a skip connection. After training, the model weights were exported as JSON files and loaded into a JUCE plugin using RTNeural for real-time C++ inference.

The models were evaluated using Error-to-Signal Ratio (ESR), DC error, other waveform-based metrics, parameter count, exported model size, and basic plugin testing. The LSTM gave the lower test-set error, while the GRU was smaller and used fewer parameters. Both models were loaded successfully in the plugin and tested in 44.1 kHz host sessions, which matched the training sample rate. Other sample rates were not validated and would require real-time-safe resampling around the neural model.

This project shows a working path from recording a hardware distortion pedal to training and deploying recurrent neural models in a plugin. It also gives a direct LSTM and GRU comparison for Boss DS-1 emulation under the same recording and deployment conditions.
