\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This dissertation examines whether compact recurrent neural networks can model the nonlinear response of a Boss DS-1 guitar distortion pedal closely enough for real-time software use. It also compares two recurrent architectures, gated recurrent units and long short-term memory networks, to assess which gives the more useful balance between accuracy, model size, and deployment efficiency.

The work follows a practice-based research approach. The main research outputs are the matched dry and processed recording dataset, the trained neural models, the model export process, and a working audio plugin. Audio was recorded from a physical Boss DS-1 under controlled conditions with the pedal controls fixed, then organised into training, validation, and test pairs. The models were trained in Python using a PyTorch pipeline and exported as JSON weight files for use in a C++ plugin.

The implemented model is a mono recurrent sequence model with one LSTM or GRU layer, a hidden size of 24, a dense output layer, and an optional skip connection. Model performance is evaluated using Error-to-Signal Ratio, DC error, parameter count, exported model size, and observed plugin behaviour. The final software artefact is a JUCE and RTNeural plugin that loads the exported models, provides Drive, Level, Model, and Bypass controls, and runs sample-by-sample recurrent inference inside the audio callback.

The study contributes a documented workflow from hardware capture to real-time plugin deployment. It addresses a focused gap in existing neural audio modelling work by comparing GRU and LSTM architectures on the same captured Boss DS-1 task, under matched recording, training, evaluation, and deployment conditions.
