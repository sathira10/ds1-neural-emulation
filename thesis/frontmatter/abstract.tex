\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This dissertation investigates whether compact recurrent neural networks can emulate the nonlinear response of a Boss DS-1 guitar distortion pedal accurately enough for real-time software use, and whether a gated recurrent unit (GRU) or long short-term memory (LSTM) architecture offers the stronger balance of accuracy and computational efficiency. The project follows a practice-based research paradigm in which original artefacts, including a matched dry/wet recording dataset, trained neural models, an export pipeline, and a deployed audio plugin, form both the method and the outcome of the study.

Original audio recordings are captured from a researcher-owned Boss DS-1 under controlled conditions at a fixed knob setting and organised as matched training, validation, and test pairs. The models are trained in Python using a CoreAudioML-style PyTorch pipeline and exported as JSON weights for real-time C\texttt{++} deployment. The current plugin-compatible architecture is a mono \texttt{SimpleRNN} sequence model with one LSTM or GRU recurrent layer, a dense output layer, hidden size 24, and an optional skip connection. Evaluation is framed around Error-to-Signal Ratio (ESR), DC error, parameter count, exported model size, and observed plugin behaviour.

The deployed artefact is a JUCE and RTNeural audio plugin that loads the exported LSTM and GRU models, exposes Drive, Level, Model, and Bypass controls, and performs sample-by-sample recurrent inference in the audio callback. Because the neural models are trained at 44.1~kHz, the final plugin design requires a real-time-safe resampling stage from the host digital audio workstation sample rate to 44.1~kHz and back for model processing. This sample-rate conversion path is identified as a required implementation and verification step rather than treated as a completed result. The study contributes a documented end-to-end workflow from hardware capture to plugin deployment and addresses a specific gap in the literature by comparing GRU and LSTM directly on Boss DS-1 emulation under matched conditions.
