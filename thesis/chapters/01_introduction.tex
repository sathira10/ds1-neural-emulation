\chapter{Introduction}
\label{chap:introduction}

\section{Background}
\label{sec:introduction-background}

Guitar distortion occupies an important position in popular music because it is not merely a defect or excess of amplification, but a recognisable creative sound. Distortion pedals shape harmonic content, sustain, dynamic response, and playing feel, making them central to many electric guitar styles. The appeal of these devices is closely tied to the nonlinear behaviour of analog circuits: the output does not scale proportionally with the input, and the resulting clipping, compression, and harmonic generation depend on both signal level and recent signal history.

This cultural importance creates a technical problem for digital audio systems. If guitarists value distortion pedals partly because of their nonlinear and dynamic analog behaviour, then a software emulation must do more than apply a simple static transfer curve. Traditional digital approaches such as waveshaping can reproduce some clipping characteristics, but they may not fully capture memory-dependent behaviour. Conversely, detailed circuit simulation can be accurate, but may be too computationally demanding for low-latency plugin use. This project therefore investigates whether compact recurrent neural networks can learn the input-output behaviour of a physical distortion pedal accurately enough for real-time deployment.

The focus of this dissertation is the neural emulation of a Boss DS-1 distortion pedal. The DS-1 is a useful target because it is a well-known and widely used distortion pedal with a recognisable sound, while also being specific enough to support a controlled study. In this project, the DS-1 is treated as a focused research object rather than as a universal representative of all distortion pedals. The aim is not to produce a general theory of distortion emulation, or a complete model of every DS-1 unit and setting. Instead, the study examines one physical DS-1 pedal at one documented knob configuration, using matched dry and processed recordings as the basis for supervised neural modelling.

\section{Problem Statement}
\label{sec:introduction-problem}

The central problem addressed by this project is the difficulty of reproducing nonlinear analog audio behaviour in real-time software. A distortion pedal does not simply apply a fixed gain or equalisation curve. Its response changes with input level, clipping behaviour, circuit dynamics, and the recent history of the signal. These properties make the device musically expressive, but they also make it harder to emulate accurately using simple digital signal processing techniques.

Static waveshaping can approximate some aspects of clipping, but it does not directly model memory-dependent behaviour. Linear convolution can capture frequency response, but it is not designed to reproduce nonlinear distortion. White-box circuit modelling can represent analog components in detail, but this approach may be too costly for practical low-latency use in a digital audio workstation. A black-box neural modelling approach offers an alternative: instead of explicitly simulating every circuit component, a model is trained to learn the relationship between an input recording and the corresponding output of the hardware device.

Recurrent neural networks are particularly relevant to this problem because they process audio as a sequence and maintain an internal state. This allows the model output at a given sample to depend not only on the current input sample, but also on previous samples. For this reason, recurrent architectures such as gated recurrent units (GRUs) and long short-term memory networks (LSTMs) are suitable candidates for modelling nonlinear, memory-dependent audio devices.

However, emulation accuracy alone is not sufficient for this project. A useful audio plugin must also run in real time, with low latency and stable performance inside a host environment. This creates a second technical concern: the chosen architecture must be compact and efficient enough for real-time C++ inference. The project therefore treats neural emulation as both an accuracy problem and a deployment problem.

\section{Research Question}
\label{sec:introduction-research-question}

This dissertation is guided by the following research question:

\begin{quote}
  How accurately can compact recurrent neural network architectures emulate the nonlinear response of a physical Boss DS-1 distortion pedal, and how suitable are these architectures for efficient real-time deployment in an audio plugin?
\end{quote}

This question combines two linked concerns. The first is objective emulation accuracy, evaluated by comparing neural model outputs against recorded pedal outputs. The second is architectural efficiency, considered through the comparison of recurrent model types and their suitability for real-time inference inside a JUCE plugin. The comparison between GRU and LSTM models is therefore not only a comparison of prediction error, but also a comparison of practical deployment suitability.

\section{Aim and Objectives}
\label{sec:introduction-aim-objectives}

The aim of this project is to design, train, export, and deploy compact recurrent neural network models for the real-time emulation of a Boss DS-1 distortion pedal. The project is practice-based: the software artefact is not separate from the research, but is the main means through which the research question is tested.

The objectives of the project are:

\begin{enumerate}

  \item To train compact recurrent neural network models using a PyTorch-based CoreAudioML-style pipeline, comparing GRU and LSTM architectures under matched conditions.

  \item To evaluate model accuracy using objective error measures based on the difference between predicted outputs and recorded pedal outputs.

  \item To export trained model weights to a format suitable for deployment and integrating the exported models into a JUCE audio plugin using RTNeural for real-time C++ inference.

  \item To evaluate the resulting plugin artefact in terms of practical real-time operation, model selection, and architectural efficiency.
\end{enumerate}

Together, these objectives position the dissertation as both an audio engineering investigation and a practice-based set of software artefacts. The research is not only concerned with whether a neural model can reduce waveform error, but also with whether the trained model can survive the practical transition from offline Python training to real-time plugin deployment.

\section{Implemented Artefacts}
\label{sec:introduction-implemented-artefacts}

The implemented system follows an end-to-end pipeline from hardware capture to plugin deployment. First, dry guitar recordings are paired with processed recordings from the Boss DS-1. These matched recordings are divided into training, validation, and test material. The training process is carried out in Python using PyTorch and a CoreAudioML-style model pipeline. The recurrent models are trained as black-box emulators that predict the pedal output from the dry input signal.

The active model architecture is a compact recurrent model with a single recurrent layer followed by a dense output layer. Both the GRU and LSTM versions use a hidden size of 24, with mono input and mono output. This hidden size is used because it matches the current plugin-compatible model format and supports real-time deployment through the C++ inference path. The trained model weights are exported as JSON files, allowing the deployment stage to avoid any dependency on Python or PyTorch at runtime.

The exported models are embedded into a JUCE plugin and loaded into RTNeural for real-time inference. This means the project tests the complete practical chain: recording a hardware device, training neural models, serialising the trained weights, loading them in a C++ plugin, and evaluating whether the resulting system can operate in a real-time audio environment. Taken together, the dataset, trained models, export pipeline, and plugin function as the project's research artefacts, with the plugin serving as the main deployment artefact and demonstration of the method.

\section{Scope and Limitations}
\label{sec:introduction-scope-limitations}

The scope of this study is deliberately narrow. The project models one physical Boss DS-1 pedal, recorded at one fixed knob setting, with Tone, Distortion, and Level held constant. The resulting models should therefore be understood as emulations of that specific captured condition rather than parameterised models of the full pedal. The study does not attempt to generalise across all DS-1 units, all hardware revisions, or all possible control settings.

The evaluation is also limited to objective comparison and plugin-level technical assessment. No formal listening study, ABX test, or MUSHRA-style perceptual evaluation is included. As a result, objective error metrics may indicate how closely the neural output matches the recorded target waveform, but they should not be treated as proof of perceptual indistinguishability.

The project also does not claim to produce a commercial-ready distortion plugin. The plugin is used as a real-time research deployment artefact for testing the trained GRU and LSTM models. Practical concerns such as sample-rate handling, model loading, bypass behaviour, and real-time inference are relevant to the evaluation, but the dissertation remains focused on the research question: whether compact recurrent architectures can emulate the captured DS-1 response accurately and efficiently enough for real-time use.
