\chapter{Conclusion}

This dissertation investigated whether compact recurrent neural network architectures can emulate the nonlinear response of a physical Boss DS-1 distortion pedal accurately enough for real-time audio plugin use, and whether GRU or LSTM models offer the stronger balance between accuracy and efficiency. The project was framed as practice-based research in which the dataset, trained models, export process, and JUCE plugin with RTNeural were treated as research artefacts rather than only supporting materials, which meant the research question had to be answered through a complete workflow from hardware recording to functional 44.1~kHz real-time deployment.

The project demonstrated that compact recurrent models can learn a useful black-box approximation of the captured DS-1 response under controlled conditions. Training on matched dry and processed recordings, the models reproduced important aspects of the pedal's nonlinear behaviour without requiring an explicit circuit model. The approach suits the DS-1 particularly well, where clipping, filtering, gain-dependent behaviour, and short-term signal memory all interact. Recurrent architectures handle this naturally: they process audio as a sequence and carry internal state, so each output can depend on recent signal history rather than only the current input sample.

Both architectures proved viable for this type of emulation. The LSTM offers a more expressive gated structure and is well suited to modelling dynamic nonlinear behaviour; the GRU uses fewer parameters and provides a more compact alternative while remaining competitive within the same deployment pipeline. The choice between them is not a question of which is universally superior, but of what a given application demands in terms of accuracy, model size, and real-time practicality.

What distinguishes this project from offline training experiments is the end-to-end implementation. The trained models were exported as JSON weight files and integrated into a JUCE plugin using RTNeural for C++ inference, covering the full path from Python-based model development to a plugin running the trained models in a 44.1~kHz real-time audio environment. Drive, Level, Model, and Bypass controls show how the neural model can sit inside a functional audio effect structure rather than remaining an offline experiment.

These conclusions, however, need to be read within their scope. The models were trained on one physical Boss DS-1 pedal at one fixed knob setting, so they should not be treated as complete models of the entire DS-1 product line or of all possible control positions. Deployment validation was also limited to 44.1~kHz host sessions, so the current prototype is not yet sample-rate independent. The project also relied mainly on objective error metrics such as ESR and DC error. These are useful for comparing predicted waveforms against recorded targets, but a lower error score does not prove perceptual indistinguishability, and it does not mean listeners would judge one model as more realistic or musically preferable.

Several directions are worth pursuing from here. The most pressing is a formal listening evaluation, such as an ABX or MUSHRA-style test, to examine whether the measured differences between models are actually audible and musically meaningful. Training parameter-conditioned models would allow Tone, Distortion, and Level to be varied rather than fixed at a single knob position. Recordings from multiple DS-1 units, a wider range of playing styles, and more extensive test material would help determine whether the approach generalises beyond the specific captured condition used here.

Compact recurrent neural networks are a practical and technically grounded approach to modelling a captured Boss DS-1 distortion response, and this project confirms that both LSTM and GRU architectures can contribute to that goal. The LSTM is the stronger expressive option; the GRU is more efficient. The real value lies in the full pipeline: hardware capture, neural training, model export, and a functional 44.1~kHz real-time plugin. Neural emulation works as a concrete development workflow for distortion plugins, not just as a theoretical framework for nonlinear audio systems, though formal CPU benchmarking and broader sample-rate validation remain open questions.
